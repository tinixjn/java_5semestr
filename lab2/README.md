Лабораторна робота №2
Тема: Збірка проєкту за допомогою Gradle та робота з Java Collections Framework.

Мета: Навчитися конфігурувати систему збірки Gradle (із використанням Version Catalogs), застосовувати стандартні колекції Java та обробляти граничні випадки.

Технологічний стек:
- Мова програмування: Java (JDK 21+)
- Система збірки: Gradle (із Version Catalog у gradle/libs.versions.toml)
- Тестування: JUnit 5

Розрахунок варіанта:
Номер варіанта визначено за порядковим номером студента у списку групи (номер 9).
Формула розрахунку: 9 mod 3 = 0.
Варіант 0: Аналізатор логів серверів (LogAnalyzer).

Опис реалізації проєкту:
- Клас LogAnalyzer реалізовано у пакеті ua.kpi.comsys.collections.
- Метод getUniqueIps використовує колекцію HashSet та регулярні вирази для фільтрації унікальних IP-адрес із логів у форматі Common Log Format, ігноруючи невалідні рядки.
- Метод getTopIps використовує HashMap для підрахунку частоти входження IP-адрес і реалізує сортування за спаданням частоти з урахуванням правила tie-breaking за лексикографічним зростанням (алфавітом).
- Усі вхідні параметри методів проходять сувору валідацію на null та невалідні значення (наприклад, topN <= 0) з викиданням IllegalArgumentException.

Покриття тестами:
- Проєкт повністю покритий юніт-тестами у класі LogAnalyzerTest.
- Перевірено роботу методів на валідних даних, порожніх списках, відсутності коректних логів, а також коректність сортування, правила tie-breaking та спрацьовування виняткових ситуацій.

Як запустити юніт-тести:
1. Відкрийте папку lab2 у середовищі розробки Visual Studio Code.
2. Перейдіть до файлу LogAnalyzerTest.java у папці тестів.
3. Натисніть зелену стрілочку запуску (значок Play) біля класу тестів у редакторі коду.
4. Перевірте успішність виконання тестів за зеленими галочками.
