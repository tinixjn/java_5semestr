Лабораторна робота №3
Тема: Опрацювання нескінченних послідовностей даних за допомогою ледачих (lazy) операцій Java Stream API, безпечне керування наявністю значень через Optional та створення кастомних проміжних операцій за допомогою Stream Gatherers.

Мета: Опанувати концепції нескінченних потоків, навчитися контролювати виконання за допомогою короткого замикання, уникати блокування та реалізувати власні статеві проміжні операції через інтерфейс java.util.stream.Gatherer.

Технологічний стек:
- Мова програмування: Java (JDK 22+ з підтримкою Stream Gatherers)
- Система збірки: Gradle
- Тестування: JUnit 5 (із використанням анотації @Timeout)

Розрахунок варіанта:
Номер варіанта визначено за порядковим номером студента у списку групи (номер 9).
Формула розрахунку: 9 mod 3 = 0.
Варіант 0: Електронна комерція та стрім транзакцій (TransactionStreamAnalyzer).

Опис реалізації проєкту:
- Модель даних Transaction реалізовано у вигляді record у пакеті ua.kpi.comsys.streams із суворою перевіркою полів на null.
- Клас TransactionStreamAnalyzer містить реалізацію методів для обробки скінченних та нескінченних потоків.
- Метод findFirstHighValueTransaction використовує ледачі операції Stream API та коротке замикання для ефективного пошуку першої транзакції, що перевищує ліміт.
- Метод takeTransactionsUntilBudgetExceeded використовує takeWhile для накопичення транзакцій у межах заданого бюджету.
- Метод processBatches реалізує кастомний Gatherer через Gatherer.ofSequential для розбиття нескінченного потоку на пакети (батчі) фіксованого розміру з обмеженням кількості через limit.
- Усі вхідні параметри проходять перевірку з викиданням IllegalArgumentException у разі невалідних даних чи null.

Покриття тестами:
- Проєкт повністю покритий юніт-тестами у класі TransactionStreamAnalyzerTest.
- Перевірено роботу методів на нескінченних потоках із використанням анотації @Timeout(2) для підтвердження відсутності зависань, а також перевірено граничні випадки та валідацію аргументів.
