Лабораторна робота №1
Тема: Сучасні можливості Java та підхід Data-Oriented Programming (DOP).

Мета: Навчитися моделювати незмінні дані за допомогою Records та Sealed Types, розділяти дані й алгоритми, реалізовувати вичерпну бізнес-логіку через Switch Expressions та Pattern Matching, а також використовувати Text Blocks.

Технологічний стек:
- Мова програмування: Java (JDK 21+)
- Засоби збірки: Maven
- Тестування: JUnit 5

Розрахунок варіанта:
Номер варіанта визначено за порядковим номером студента у списку групи (номер 9).
Формула розрахунку: 9 mod 3 = 0.
Варіант 0: Система управління замовленнями.

Опис реалізації проєкту:
- Усі класи та інтерфейси реалізовані у заданому пакеті ua.kpi.comsys.dop.
- Ієрархія даних побудована за допомогою sealed interface OrderStatus та записів Pending, Paid, Shipped, Cancelled.
- У конструкторах записів реалізовано сувору валідацію вхідних параметрів (перевірка paymentID, amount, trackingCode, dispatchDate та reason на null, порожнечу чи некоректні значення) із викиданням IllegalArgumentException у разі невідповідності умовам.
- Бізнес-логіку обробки статусів винесено в окремий клас-обробник OrderProcessor.
- Метод process містить перевірку на null та використовує switch expression з pattern matching для трансформації даних у форматовані Text Blocks.

Структура проєкту:
- Пакет ua.kpi.comsys.dop у папці src/main/java містить класи OrderStatus.java та OrderProcessor.java.
- Пакет тестів у папці src/test/java містить клас OrderProcessorTest.java для перевірки всіх гілок коду та виняткових ситуацій.

Як запустити юніт-тести:
1. Відкрийте проєкт у середовищі розробки Visual Studio Code.
2. Перейдіть до файлу OrderProcessorTest.java, який розташований у папці тестів.
3. Знайдіть біля назви класу або тестових методів зелені стрілочки запуску (значки Play), які з'являються зліва від номерів рядків у редакторі коду.
4. Натисніть зелену стрілочку біля класу OrderProcessorTest, щоб виконати весь набір юніт-тестів.
5. Перегляньте результати виконання у вигляді зелених галочок у середовищі розробки та у звіті виконання.
